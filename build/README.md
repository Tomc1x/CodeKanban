# Icône de l'app

Remplacez `icon.png` par le vrai logo (carré, fond de préférence transparent,
1024×1024 recommandé, 512×512 minimum, format PNG). `electron-builder` génère
automatiquement les formats spécifiques à chaque plateforme (`.ico` pour
Windows, tailles multiples pour Linux) à partir de ce fichier unique — aucune
autre configuration n'est nécessaire.

Le fichier actuel est un placeholder (aplat de couleur) généré pour que le
build ne casse pas tant que le vrai logo n'est pas fourni.
